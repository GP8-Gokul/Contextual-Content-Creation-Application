# Adaptive Content Generation System Using Reference Analysis and Artificial Intelligence

A BTech Mini Project submitted to APJ Abdul Kalam Technological University  
by N JAGANNATHAN, GOKUL P JAYAN, GOKUL KRISHNA, ADITH KURIAN

## 📘 Project Overview

This application uses artificial intelligence and natural language processing to assist users in generating study materials by analyzing user-uploaded reference documents. It minimizes manual effort and allows for content personalization using keyword-based search and summarization.

## 🎯 Objectives

- Automate personalized study material generation.
- Extract relevant content from user-provided references.
- Summarize and organize data based on keywords.
- Improve learning by enhancing content comprehension.

## 🧠 Key Features

- PDF content extraction
- Keyword-based content mapping
- AI-powered summarization
- User-friendly Flutter frontend
- Flask-based backend integration
- Firebase for database and authentication

## 📐 System Design

### 🧱 Core Modules

1. **PDF Extraction** - Extracts and cleans text from uploaded PDFs.
2. **Keyword Classification** - Maps content to user-defined keywords using NLP.
3. **Summarization** - Generates short summaries of keyword-relevant content.


## 💻 Technology Stack

| Component   | Technology |
|-------------|------------|
| Frontend    | Flutter    |
| Backend     | Python Flask |
